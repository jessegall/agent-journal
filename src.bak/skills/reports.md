# Reports and docs

Use a report for what was checked or researched now. Use a doc for knowledge that should remain true and be found later. Use a plan for approved phases of future work. Use a tool for a script worth running again.

Research, audits, measurements and delegated investigation end in `journal report create`. Lead with the answer, then the evidence, what was already sound, and what remains uncertain. A report describes what was found now; promote enduring knowledge into a doc rather than treating a temporary result as permanent.

Read the doc catalogue before re-investigating a subject it may settle. Lasting material is written with `journal doc create` and `journal doc section`; text that is already written, in a file or the conversation, is filed whole with `journal doc file "<title>" <file>`, which makes each heading a chapter and skips writing it chapter by chapter; attach supporting files through the doc controller. Catalogue a reusable script with `journal tool create`.

Subagents report to you; you compile their findings into the report or doc for the user.
