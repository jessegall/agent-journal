Agent settings

One window for how the main agent works and what its helpers and workers may do, following doc 1218 sections 4 to 12. The Agents tab is the accepted Agent counts design (doc 1215) with its rows extended. It is opened from the top bar, or from the Agent counts button, which opens the Agents tab. Every frame is live: switch tabs, change a control and press Apply. All data is invented.

The words in the window speak to the person about what they get, not about how the journal decides.

The top bar

Auto, the current way of working and a settings button. Choosing Builder or Orchestrator in the menu sets those switches at once. Custom cannot be chosen from the menu; it is what the bar says when the person has set their own.

The window seen by an agent

Only a person changes these settings. An agent sees the window read-only: every value and where it comes from, and nothing it can press changes one. The main agent has one Ask for a change button at the top of each tab. It writes what should change and why, the request goes through the existing request path, and the tab then says it is waiting for a person. A helper or worker is told to raise a needed change in its report to the main agent.
