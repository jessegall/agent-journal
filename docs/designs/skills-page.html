A Skills page of its own

The Skills page of the agent-journal viewer: a list of every skill, one switch for Required on each, and triggers that make an agent read a skill when your words appear. Every frame below is live: click rows, switches and buttons. All data is invented.

I pick 1a for the page and 2a for the trigger form. Reasons are under each.

The page: list and open skill

1a is my pick. The list stays beside the open skill, so you can switch Required on several skills and read one without losing your place. Version 4 had this list but opened a skill in a panel that slid over it. Each skill keeps its own address, so it can be linked. 1b is closer to version 4: more room per row, but opening a skill leaves the list.

1aList beside the open skill, dark, with a skill open (my pick)
1aLight, nothing open yet
1bFull width list, dark. A click opens the skill as its own view with a way back

Adding and editing a trigger

2a is my pick. The form opens in place, inside the skill, so the skill is already chosen. Only the words are needed: type one, press Enter, save. The rest has a sensible start: it watches what you write, and matches whole words so that "plan" does not fire on "planet". 2b is the existing trigger dialog with one more action. It is cheaper to build, but it asks for a name and offers everything a trigger can do, which is a lot for a keyword.
