House style

Four purple house styles for the journal, each in light and dark, drawn on the same screens. Every colour is one of the version 6 token names in resources/css/app.css, so an option is a drop-in swap of the :root and .dark blocks plus four new tokens. The primary button becomes a solid brand fill; today's dim-fill primary stays available as “tonal”. Contrast is computed on this page from the values shown.
