The agent status dot

Three changes to the agent's header, its information bar and the rows of the agents and helpers lists. The bar under an agent's header is the information bar: that is its name in the code (src/viewer/src/shell/InformationBar.vue, marked data-information-bar).

1. The information bar no longer shows the run time or its clock icon. 2. The header says "Started 6 hours ago" and "Last heard just now" as plain text, with no clock icon. 3. The status dot leaves the left of the row and sits in its top-right corner: it pulses while the agent works, stays still otherwise, and on hover or focus says what the agent is doing and since when. A row no longer shows its age.

Hover a dot in any frame to see its tooltip. All data is invented.

The agent's header and the information bar

The header keeps the session's run time, 7m, beside the dot. The line under it says when the agent was first started and when it was last heard from, in words. The information bar keeps the program, context, model, effort, cost and branch, without the run time.

The rows of the agents and helpers lists

The left edge is free, so the type and name line up with the job. The corner holds the dot and nothing else: no dispatch time, no age. The words that matter for a stuck agent, such as "Waiting: tests" and "Blocked", stay on the row.

What the dot says

It pulses only while the agent itself is doing something. The colour is never the only sign: the tooltip always says the state in words, and the dot is a button a keyboard can reach, so the tooltip opens on focus too. With reduced motion on, a pulsing dot shows a still halo instead.
