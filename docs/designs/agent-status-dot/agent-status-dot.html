The agent status dot

The agent's header, its information bar and the rows of the agents and helpers lists. The bar under an agent's header is the information bar: that is its name in the code (src/viewer/src/shell/InformationBar.vue, marked data-information-bar).

A row has three lines and nothing more: the title, the subtitle with program, model, effort and role, and the task line. The task line says only "Task" and its number, with how many of its tasks the agent has done at the far right, and a thin bar under it. The rest is in tooltips: the dot says what the agent is doing and since when, the task says its title, and the count says what is left. Hover the dot, the task or the count in any frame. All data is invented.

The rows of the agents and helpers lists

The bar has one short segment per task. A done task is filled, a task still to come is empty, and the task in hand fills as it comes along: a third when it starts, two thirds when it is being tested. It takes the colour of the dot, so a blocked task shows in amber and one waiting for its tests in teal. A helper has a job, not tasks, so its line says "Job" and its tooltip holds the question, with no count and no bar.

What the dot says

It pulses only while the agent itself is doing something. The colour is never the only sign: the tooltip always says the state in words, and the dot is a button a keyboard can reach, so the tooltip opens on focus too. With reduced motion on, a pulsing dot shows a still halo instead.
