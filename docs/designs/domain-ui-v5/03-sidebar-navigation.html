03 · The sidebar with nested navigation

This is version 5's sidebar (shell/SidebarPages.vue): 220 px wide; a fold-head per group (11 px, weight 600, uppercase); rows with 6×8 padding and a 7 px radius; a 13 px window icon (14 px for Home); the count at the right; the foot line. The list scrolls with its scrollbar hidden, and the 52 px mini form shows icons only. New in version 6: a row may hold child rows to any depth. The link opens the page; the separate chevron opens or closes the children without navigating. The phone keeps version 5's phone layout. It is drawn as version 5 draws it, and nested navigation does not appear there yet.

Expanded, collapsed, mini and phone

A: every level open. The current page sits five levels deep and the list scrolls on past the bottom edge. Indentation stops after level 3, where the branch line turns dashed. A long label ends in an ellipsis, and the tooltip shows the full label and its path. Levels 3 to 5 are records the Notes module lists per request. B: the same tree with Notes closed: the dot says the current page is inside. The Agents group is folded, and a folded fold-head shows nothing more, as in version 5. C: mini sidebar. Fold-heads are hidden, rows sit 2 px apart and only root rows show. A parent opens its own page, or its first child when it has no page. D: phone, as in version 5: one window, and the phone bar lists the layout's windows with their counts, scrolling sideways.
