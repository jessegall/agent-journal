01 · The shell and Home with its windows

Version 5's shell as it runs (src/viewer/src/windows/PaneStage.vue): the 220 px sidebar, the 40 px breadcrumb with the top buttons, the 54 px agent bar, the 30 px information bar, then the pane grid. Every window in a pane, every sidebar row and every docked card here comes from a domain's declaration. Pink labels name the declaring domain; teal labels mark what version 5 did not have.

Home · three panes and one detached window

Left pane: Chat (ChatDomain's window). Right top: Plans, Rules and Notes as tabs in one pane. Right bottom: Rules. Floating: Notes · Decisions, detached from a pane. The dock above the composer holds a Plans card and a card from the outside Notes module (slot chat.dock). The bar carries a Notes section (slot shell.bar).
