Task list rows

The rows of the Tasks window, cleaned up. The status ring, the number, the title and the reason a task waits stay as they are. Three things move into icons in fixed columns at the right, so they line up from row to row: the agent on the task, its complexity and its priority. The tags, still written in full, follow the title, so a row reads as the task and what it is about, then its facts.

Every icon has a tooltip saying what it means. Hovering the priority icon opens a small menu to change it; a click or Enter opens it too, for a keyboard or a touch screen. Hover anything in the frames. All data is invented.

The rows

The agent is its initials in a small circle: a solid ring when the agent holds the task, a dashed one when the task waits for it. Complexity is five rising bars, as many filled as its score, turning amber at 4 and 5. Priority keeps its chevrons. A task with no complexity or no agent leaves that column empty, so the columns never shift.
