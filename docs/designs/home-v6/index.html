Grows
Window

Four ways Home could grow, kept basic so they can be felt rather than read. All four start the same: just the chat, centred at a 760 px reading width however wide the window. They differ in what happens once the user adds a window. In every one, Space (outside a text field) or the + in the agent bar opens the quick-add menu; drag the menu to where the window should go and press Enter, or drag a row onto the desk. Pick a variant, then step through how a user grows it, or build your own from step 1.
