# Words no declared name may hold, one to a line, a tab, then why. name-faults.php refuses a name that holds one. A
# word is matched whole, after a name is split at its capitals and underscores. A line starting with verb: names an
# action's first word (its verb) that has a better coding word; the word stays free as a noun elsewhere.
verb:report	an action that tells someone something happened notifies: say notify (NotifyStop, not ReportStop)
underway	say what state it is in: pending, active or running
begun	an event names what happened, not that something started: say what started (StopRequested, AttemptStarted)
legacy	version 6 holds no old code (rule 87); name what the thing is now
deprecated	version 6 holds no old code (rule 87)
obsolete	version 6 holds no old code; say what changed (outdated, superseded)
magic	poetry: say what it does
stuff	vague: say what it holds
thing	vague: say what it is
things	vague: say what they are
whisper	poetry: say what is sent
tale	poetry: say what is told
said	poetry: say what is written or sent
misc	vague: group by subject
util	vague: name the subject
utils	vague: name the subject
foo	placeholder
baz	placeholder
dummy	vague: say what it stands in for
hack	say what it does
frontier	poetry: say which item it is (the last shown)
journeys	poetry: say what is done (tasks, flows)
tombstone	poetry: say what is kept (a refused key, a retention end)
survivors	poetry: say what is left running
climbs	poetry: say what the path does (escapes its root)
foot	poetry: say where (bottom)
leader	poetry: say what it is (the first, the leading source)
currency	ambiguous: say whether it is current
mine	not a coding word: say whose (own, the caller's)
yours	not a coding word: say whose (another actor's, not the caller's)
former	not a coding word: say previous, or name what it is now
theirs	not a coding word: name what it holds (the other value, the second class)
ours	not a coding word: name what it holds
