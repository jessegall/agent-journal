# To-dos and work

A distinct task that is not current becomes `journal todo add`. Put evidence, scope and a starting point in its brief. Use `todo after` for another row, `todo block` for an external condition, and `todo ask` for a user decision. Auto mode takes the next ready row by priority.

Start with `journal todo start`; update the linked work as direction changes. End the work with `journal work end`, then close the row with `journal todo done`. Never leave completion implicit.
