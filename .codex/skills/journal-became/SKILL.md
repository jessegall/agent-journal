# Message tracing

A row the agent files while a message is in its hands is linked to that message, without a declaration.

The message the agent read last and has not closed is the one in hand; every to-do, pin, rule, reminder, question, doc, report, plan or work it creates meanwhile is linked to it and shows as a pill on the turn.

It listens to: created. It speaks on the events it listens to. On by default; the viewer's Settings switches it per environment, and `triggers.became` in the environment's settings tunes it.
