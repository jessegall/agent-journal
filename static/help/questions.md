# Questions

A question is the agent asking you something only you can decide.

## How it works

Asking never stops the agent. It files the question and carries on with whatever does not depend on the answer, and it is told as soon as you answer.

A question can come with a few **options** to click. The one the agent recommends is marked **Agent's pick**. You can always write your own answer instead.

## What you can do

- Answer an open question: pick an option and save, or write your own.
- Change an answer later with **Change answer**. The old answer is kept, and the agent is told again.
- See what a question is about: a to-do, a document, a pin, a rule or a message.
