# Reports

A report is something the agent wrote for you to read: the result of something you asked it to check, investigate or research.

## How it differs from a document

A report is written for you, once. It is not handed to later agent sessions the way documents and pins are. If a report turns out to hold something the project should keep, it can be turned into a document.

## What you can do

- Read a report, and see what it is about, such as the to-do it answers.
- Archive it once you are done with it.

Reports older than a set number of days are archived automatically. Change that number on the environment's **Settings** page.
