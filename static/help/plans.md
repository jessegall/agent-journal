# Plans

A plan says what will be done on this environment and in what order. It is split into phases, and each phase is a set of to-dos.

## How it works

- A plan starts as a draft. The agent writes it, with its goal, its phases and the to-dos in each phase.
- You approve it. Only you can make a plan active, and one plan is active per environment at a time.
- The agent works the current phase: the first phase that is not complete. It does not start a later phase early.
- A phase is complete when all its to-dos are done. It gets its check mark on its own.
- A phase marked as a checkpoint stops the agent once it is complete. You press Continue to let it start the next phase.
- You get a notification each time a phase completes. The plan is done when its last phase is.

## How it differs from a document

A plan ends when the work ends. A document is for what stays true afterwards: how something works, a library, a ruling. A report is what an agent found when it looked into something.

## What you can do

- Approve a draft, or continue past a checkpoint.
- Add a phase, put to-dos in a phase, or link a document or report.
- Abandon a plan, with a reason.
