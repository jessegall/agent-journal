# Welcome desk field notes

- The reading room opens at 09:00 on Saturday. The first volunteer arrives at 08:45.
- The key is in the blue lockbox. The code is given in person by the coordinator, never written in the guide.
- Put the sign outside, turn on the desk lamp and check that the visitor register has a blank page.
- At 12:00, hand the register and the desk key to the next volunteer. Tell them about any books waiting for collection.
- At 16:00, bring in the sign, switch off the lamp and return the key to the lockbox.
- If a visitor asks about an unlisted book, write the title on the request card for the coordinator.
