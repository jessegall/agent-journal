# Messages

Read waiting messages with `journal message unread` and mark one seen with `message read`. Reply when the user needs an answer; react when acknowledgement is enough. When part of a message becomes a to-do, pin, rule, reminder, question, doc, report, plan or work, record that exact part with `message process` so its pill links to the resource.

Finish with `message processed --how`. A status sentence is not a link, and a link is not an answer. File attachments through `message file`; archive only when the message needs no action.
