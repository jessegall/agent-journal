# Questions

Use `journal question ask` for a decision only the user can make, with two or three mutually exclusive options in `options`. Link it to the row it blocks. Do not stop the whole session when other ready work exists; auto mode skips the waiting row and continues.

Choices written only in prose are not a question resource and can hold the agent until corrected.
