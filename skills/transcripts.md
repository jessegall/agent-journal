# Transcripts

Read the whole transcript before filing anything. Separate decisions and work from discussion, search the record for existing rows, then file a few coarse to-dos rather than one per sentence. Quote the user's own words when recording what a message became.

A transcript is declared, not inferred from length. If an attached text file is unmistakably a conversation, declare it and tell the user. Plans derived from it remain drafts until the user activates them; lasting conclusions belong in docs.
