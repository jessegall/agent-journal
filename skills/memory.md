# Memory

A fact is something true about the environment that a later session would get wrong without. A rule is a decision that binds every environment. A reminder is an instruction likely to be forgotten. One future action is a to-do, not memory.

Write reasoning in the brief. At a context mark, answer with `journal fact create`, `journal rule create`, or `journal nothing`. Retire claims that stopped being true with `fact strike` or `rule strike`; `journal rule reread` reads every standing fact and rule again, and the record audit names what has evidence against it.
