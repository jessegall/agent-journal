# Memory

A pin is a fact a later session would get wrong without. A rule is a decision that binds every environment. A reminder is an instruction likely to be forgotten. One future action is a to-do, not memory.

Write reasoning in the brief. At a context mark, answer with `journal pin create`, `journal rule create`, or `journal nothing`. Retire claims that stopped being true with `pin strike` or `rule strike`; use the cleanup reading pass as well as its mechanical evidence.
