engine  The building blocks every module stands on; it imports no module.
  contract
    actor  Who acts on the journal: the actor a command carries, and the check that an actor is a person.
    agent  What the engine knows of agents: groups, roles, policy, checkouts and where an agent may write.
    area  The marker every engine area folder declares itself with: what the area is for and who may import it.
    bookkeeping  The read commands of the event log and the refusal log.
    caller  Who runs a command line: the caller, its request and the chain of processes it came through.
    chat  Declarations of chat marks, their buttons and docked items.
    check  The conditions a step or a periodic check tests.
    checkout  A checkout of the project and a file in it.
    cli  The command line: parsing a line, the default subcommands of a model and running a line on the console.
    command  Commands, their handlers and the bus that runs them, with the approvals a person gives.
    connection  The connection to the server's socket and the check for an internet connection.
    container  The container that builds a class with what it needs, and the container of one journal.
    database  The database: tables, migrations, statements and the count of repeated work.
    dotted_path  A dotted path to a class, and loading the class it names.
    driver  Drivers, suites, driver rules and overlays: how the journal answers the hooks of an agent.
    environment  The names of environments.
    event  Events: what a change to a row raises, the event log, event types and event patterns.
    file  Reading and writing files in one place, with file versions, fingerprints and conflicts.
    git  Git reads of the project's files and of hook files.
    guard  Guards that can refuse a change, their switches and the lifecycle guard.
    helper_type  The types of helper a module can add, and the book of them.
    hosting  Running the journal as a hosted service: the checks of the host, and hosted files.
    instruction  The imports in the instruction files of an agent.
    journal  The journal and its home folder.
    json  JSON pointers, JSON schemas and settings files.
    library  The team library: items, shares, lookups and what a show command adds from it.
    listener  Listeners that run on a save, a deletion or a commit, and the runner of commit listeners.
    log  The error log, the refusal log and the writer of the system log.
    map  The map of the code: one line for each top folder, engine area, module, suite and tunnel.
    model  Models: rows with their states, lifecycles, scopes and positions.
    module  Modules: the declaration, its checks, the sync into the registry and the layer rules.
    performance  Developer tools that measure how fast the journal runs.
    plan  Who may write a plan.
    private  Private folders, secret values and the keys of the server.
    process  Child processes, processes left over from an earlier run and the processes of plugin scripts.
    profile  The profile of an agent and its name.
    provider  Providers of agent programs: hooks, launches, models and the context window.
    query  Queries: conditions, filters, pages and shared rows.
    registry  The registry: everything the loaded modules declare, read from the database.
    repository  Saving and loading rows, with the check for a stale row.
    request  The queue of requests and its entries.
    row  What every row has: metadata, a page of rows and the owner of a row.
    sandbox  The sandbox of an agent and of a shell line.
    scope  Scopes: which rows an actor or an environment may read.
    seed  Seeders and the demo data.
    serving  What the server and the installer share: the server's files and limits, the handover of code, the update steps.
    setting  Settings: declarations, rules, groups and the reading of values.
    skill  Skills: declarations, contents, digests and the shape a skill must have.
    subcommand  Subcommands: arguments, output and how rows and values are printed.
    template  The declaration of a template.
    text  Text helpers: explanations, search terms and digests.
    ticker  Timed handlers: which are due and how often one runs.
    time  The clock, timestamps, durations, deadlines and timings.
    tunnel  The contract of a tunnel.
    types  Type guards.
    upgrade  Moving a version 4 journal into version 5: the moves, their report and the runner.
    version  The versions of the code and of the journal.
    viewer  Declarations for the viewer: windows, buttons, inspectors and fields.
  internal
    script  The record of a plugin script that was left out, and why.
    testing  The test kit: the story builder, expectations, fakes and examples.
core  The modules that come with every journal.
  accounts  The people who can log in to a hosted journal: their logins, sessions and second factors. Needs: journal.core.actors.
  actors  Gives the actors table, which the core owns, its commands: journal actor make, show, list, edit and delete.
  agents  Adds agents, one per session of an agent program, each an actor with the same number. Needs: journal.core.actors, journal.core.environments, journal.core.chat.
  aliases  Adds aliases: words of the project's own that run a shell line, `journal <name> [args]`. Needs: journal.core.actors, journal.core.agents, journal.core.processes, journal.core.plugins, journal.core.drivers.
  approvals  Asks for every person-only approval through one persistent dock card. Needs: journal.core.agents, journal.core.actors, journal.core.environments, journal.core.docking, journal.core.viewer, journal.core.chat, journal.core.drivers, journal.core.settings.
  assign_rules  Adds a person's standing rules that give new free tasks to the main agent, one agent or a kind of agent. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.tasks, journal.core.plans.
  assignments  Adds assignments: any row of a model that declares itself assignable can be given to actors. Needs: journal.core.actors, journal.core.agents.
  chat  Adds the marks in an environment's chat, of the types modules declare. Needs: journal.core.actors, journal.core.environments, journal.core.settings.
  claude_code  Adds Claude Code as an agent program.
  codex  Adds Codex as an agent program.
  demo  Adds the demo: a journal filled by the seeders of the modules, and a scratch server that shows it. Needs: journal.core.actors.
  developer  Adds the developer settings: one switch and the groups inside it, for working on the journal itself. Needs: journal.core.settings, journal.core.chat, journal.core.environments, journal.core.agents.
  docking  Adds the dock above an environment's chat and the items modules dock in it. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.chat, journal.core.settings.
  documents  Adds documents, which keep lasting information about the project, reports of what was checked at one time, a document's revisions, and links between rows. Needs: journal.core.actors, journal.core.environments, journal.core.settings, journal.core.messages, journal.core.tasks, journal.core.plans, journal.core.docking, journal.core.agents, journal.core.drivers, journal.core.processes, journal.core.chat.
  drivers  Keeps every hook's decision, the lines waiting for agents and the rules' history, and answers hooks through the suites, drivers and rules of the installed modules. Needs: journal.core.chat, journal.core.developer, journal.core.actors, journal.core.environments, journal.core.agents, journal.core.settings, journal.core.profiles.
  dumps  Adds dumps: notes and files the user adds, which the agent makes rows from, item by item. Needs: journal.core.actors, journal.core.environments, journal.core.docking, journal.core.agents, journal.core.drivers.
  environments  Adds environments, the checkouts where work happens, and lets --environment name one. Needs: journal.core.actors.
  helpers  Starts and keeps helpers: extra agents the journal runs on any program, for a parent that hears from them by message. Needs: journal.core.agents, journal.core.profiles, journal.core.messages, journal.core.drivers, journal.core.usage, journal.core.chat, journal.core.skills, journal.core.settings, journal.core.processes, journal.core.environments, journal.core.tasks.
  library  Connects this journal to a team's shared server, and keeps the items a person got in step with it. Needs: journal.core.actors, journal.core.settings, journal.core.documents, journal.core.secrets, journal.core.agents.
  mcp  Adds MCP servers: the suggested ones installed by name into Claude Code's .mcp.json and Codex's .codex/config.toml with their keys only as variables, the keys kept outside the project and given to the agent programs at launch, and the Integrations window. Needs: journal.core.actors, journal.core.agents, journal.core.secrets.
  memories  Adds memories: what the journal gives back to an agent, weighed and fading, with the keywords that bring one back and the context marks that ask the agent to weigh them. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.tasks, journal.core.settings, journal.core.chat, journal.core.docking, journal.core.drivers, journal.core.documents.
  messages  Adds messages: what the user, the agents and the journal say in an environment's chat. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.chat, journal.core.docking, journal.core.pins, journal.core.drivers, journal.core.dumps, journal.core.settings, journal.core.schedules, journal.core.profiles.
  overview  Adds journal overview, a page of what is open or running that shows the commands the user chooses, and which an agent must run first when its session starts or is compacted. Needs: journal.core.settings, journal.core.drivers.
  phone  Pairs a person's phone with the viewer by a short code, and keeps each paired phone until it is unpaired. Needs: journal.core.actors, journal.core.settings, journal.core.tunnel, journal.core.questions, journal.core.plans, journal.core.agents.
  pins  Adds pins: links pinned above an environment's chat for the person to open on their return. Needs: journal.core.actors, journal.core.environments, journal.core.drivers.
  plan_reviews  Lets a person ask for a critique of a plan and shows its review rounds, added to the plan module from outside it, with the same means any module has. Needs: journal.core.agents, journal.core.documents, journal.core.drivers, journal.core.plans, journal.core.skills, journal.core.templates, journal.core.viewer, journal.core.actors.
  plans  Adds plans: a goal, its phases in order, and the tasks placed in each. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.tasks, journal.core.chat, journal.core.docking, journal.core.drivers, journal.core.messages.
  plugins  Adds plugins: programs the person installs into the journal, switches on or off and configures, which an agent may only propose. Needs: journal.core.actors, journal.core.environments, journal.core.settings, journal.core.drivers, journal.core.chat, journal.core.skills, journal.core.processes, journal.core.agents, journal.core.messages.
  processes  Adds processes: every shell line an agent runs is kept as a numbered process with its parts and its output. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.drivers, journal.core.waits, journal.core.messages, journal.core.chat, journal.core.docking, journal.core.tasks, journal.core.settings, journal.core.developer, journal.core.assignments.
  profiles  Publishes declared agent profiles and provides their list and editing commands. Needs: journal.core.actors, journal.core.agents, journal.core.settings.
  project_rules  Adds project rules: standing instructions every agent gets at its start, which a person approves. Needs: journal.core.actors, journal.core.agents, journal.core.drivers, journal.core.docking, journal.core.memories, journal.core.reminders, journal.core.settings, journal.core.viewer.
  questions  Adds questions an agent asks the user, with the options it offers and the answer it gets. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.messages, journal.core.waits, journal.core.chat, journal.core.documents, journal.core.tasks, journal.core.plans, journal.core.docking.
  reminders  Adds reminders: what an agent is told at a date and time or on an interval, once or repeating, and may be held to with a block, and the Reminders page. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.drivers, journal.core.tasks, journal.core.memories, journal.core.chat.
  reviews  Adds reviews, requests to have a row's work checked point by point by a reviewer. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.settings, journal.core.chat, journal.core.plans.
  schedules  Adds the record of the jobs an agent schedules in its own program, and a person's way to have one stopped. Needs: journal.core.actors, journal.core.agents, journal.core.environments, journal.core.drivers, journal.core.chat.
  search  Adds search: the rows of every model that names its search fields, found by the terms they hold, and the chat mark of an agent's search. Needs: journal.core.actors, journal.core.chat, journal.core.drivers, journal.core.processes.
  secrets  Adds secrets: keys and logins the agent gives to programs without seeing them, their values in a file outside the project, the Secrets window where the user types them and allows programs, and the guards that keep a value out of every tool and row. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.messages.
  sequences  Adds sequences: steps an agent works through in order, taking each up before it edits, one run at a time. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.drivers, journal.core.chat, journal.core.documents, journal.core.plans, journal.core.questions.
  setting_components  Adds the setting components: the pieces a settings screen is drawn from, one for each value of the setting component enum, which a window imports as @journal/setting-components.
  setting_requests  Sends setting changes that require a person to the shared approval dock. Needs: journal.core.actors, journal.core.environments, journal.core.settings, journal.core.questions, journal.core.approvals.
  settings  Adds settings: values kept for an environment or for the whole project, set and read by the keys modules declare, a secret kept apart from the event log. Needs: journal.core.actors, journal.core.environments.
  sharing  Lets a person share a document, a report or a plan as a read-only link, kept by the digest of its token until it expires or is revoked; an agent may ask for one, and visitors may comment if the link lets them.   skills  Publishes skills and tracks what each agent must read. Needs: journal.core.actors, journal.core.agents, journal.core.drivers, journal.core.settings, journal.core.chat, journal.core.processes, journal.core.environments, journal.core.profiles.
  suggestions  Adds suggestions the journal offers the person once, shown as a chat mark the person accepts or declines. Needs: journal.core.actors, journal.core.environments, journal.core.chat.
  tasks  Adds tasks, units of work current by an agent, with their log lines and dependencies, and the rules that keep an agent at its task.   templates  Adds templates: reusable shapes for tasks, plans and critiques, and the testing template a plan runs at each phase end. Needs: journal.core.actors, journal.core.drivers, journal.core.messages, journal.core.documents, journal.core.plans, journal.core.agents, journal.core.skills.
  tools  Adds the tools the journal supports, starting with Graphify: a card for each on the Tools page to install, turn on or off and refresh, and a managed hook, held for every agent program while a tool is on, that refreshes Graphify's graph in the background after each new commit.   transcriptions  Adds transcriptions: transcripts kept in the project, pasted or fetched, which an agent turns into summaries and other rows linked back to them, and the Transcriptions page.   usage  Adds usage and cost: what each open session's status line reported of its model, context and cost, the plan's windows, and the project's counts, shown on the Usage window. Needs: journal.core.actors, journal.core.environments, journal.core.agents, journal.core.settings, journal.core.drivers.
  voices  Adds the voice the agent talks to you in, the title and first name it calls you by, and whether the chat shows a figure: chosen with journal voice, and told to the main agent when it starts, after a compaction and when it changes.
