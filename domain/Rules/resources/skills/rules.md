# Rules

## What a rule is

A rule is a standing instruction every agent of the project is told. It holds only while it is active.

## States

A rule is proposed with its text, then approved by the user and active, or denied. An active rule can be removed later; a removed or denied rule no longer holds.

## Reading rules

Your overview names how many rules hold and the call that lists them. Read every active rule before you work; a rule holds for every agent, you included.
