# Plain English in code

Write all code in plain English: name every class, method, variable, file and message with ordinary words and the terms commonly used in programming. Never invent words, use rare or poetic words, or coin your own jargon.

Class, interface, enum and trait names are short names, never sentences with a clause in them: a noun or noun phrase for what the type is or the role it plays (`StackTarget`, `PageProvider`, `MessageSender`), never a verb phrase about what its implementer does (`ProvidesPages`, rule 43) and never a name like `ChangesWhatUsersSee` (rule 24). Traits and attributes keep verb names (`HasComments`).
