# Notifications

Every act of the agent the user should hear of becomes a notification.

A type that does not notify the user makes none; the agent may write one itself to say a long piece of work landed.

It listens to: *. It speaks on the events it listens to. On by default; the viewer's Settings switches it per environment, and `triggers.notifications` in the environment's settings tunes it.
