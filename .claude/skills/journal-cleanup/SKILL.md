# Cleanup

What in the record has evidence against it, said to the agent once a day; and the reading pass it owes.

cleanup lists claims naming a file that is gone or a verb the CLI lacks, and rows waiting on the user too long; cleanup read is every rule and pin in full.

It listens to: agent.updated. It speaks every 1440 minutes. On by default; the viewer's Settings switches it per environment, and `triggers.cleanup` in the environment's settings tunes it.
