# The inbox

Unread messages are named after a tool use, again and again, and past a patience they hold the agent's writes.

journal message unread lists them; reading each one marks it read and lifts the hold. triggers.inbox sets how often, settings inbox.patience how many times before the hold.

It listens to: agent.updated. It speaks every 1 uses. On by default; the viewer's Settings switches it per environment, and `triggers.inbox` in the environment's settings tunes it.
