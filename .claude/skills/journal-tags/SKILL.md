# Tags

The agent's last message opens with one tag, or it is told so once.

[!discovery] [!correction] [!blocked] [!info] [!reply]

It listens to: agent.updated. It speaks on idle. On by default; the viewer's Settings switches it per environment, and `triggers.tags` in the environment's settings tunes it.
