# Reminders

The standing reminders said again to the agent when it comes to rest after work.

Said at an idle that follows tool use, not at every stop: three replies in a row hear them once. Set triggers.reminders to {every, unit} or {on} to change it.

It listens to: agent.updated. It speaks on worked. On by default; the viewer's Settings switches it per environment, and `triggers.reminders` in the environment's settings tunes it.
