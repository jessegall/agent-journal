# Deferral

Work put off in words, with no to-do parked, is named back to the agent once.

A sentence like 'I'll do that after this' is the title of a to-do; park it before the reply goes out.

It listens to: agent.updated. It speaks on idle. On by default; the viewer's Settings switches it per environment, and `triggers.deferral` in the environment's settings tunes it.
