# Reports, docs, plans and tools

Use a report for what was checked or researched now. Use a doc for knowledge that should remain true and be found later. Use a plan for approved phases of future work. Use a tool for a script worth running again.

Read the doc catalogue before re-investigating a subject it may settle. Research ends with `journal report create`. Lasting material is written with `journal doc create` and `journal doc section`; attach supporting files through the doc controller. Plans are drafted with `journal plan create`, divided with `plan phase`, linked to rows with `plan todos`, and approved by the user and then started by you. Catalogue a reusable script with `journal tool create`.

Subagents report to you; you file the report or doc.
