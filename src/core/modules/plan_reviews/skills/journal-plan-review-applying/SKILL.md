# Applying a plan's reviews

Working a critique into a plan is a light job. Be done quickly.

- For each finding, name the step or the change it makes: a new task, a wider brief, or a different order. Give a
  short excerpt or `file:line`, never the solution written in advance.
- Trust the reviewer's reference. Check only the findings you reject, and say why in one line.
- Put each change in the plan with `journal task make`, `journal phase place` and `journal task edit`.
- File one report of what the reviews found and what you did with it, then end the review with
  `journal plan reviewed <plan n>`.

How thorough the tasks are is in the skill journal-planning; the commands are in the skill journal-plans.
